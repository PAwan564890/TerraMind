# Verification, limitations and future scope

Final handover rerun: **831 backend tests**, **62 React tests**, **9 development browser checks**, **9 production-preview browser checks**, TypeScript checks and production build passed. Logs are local ignored `work/handover-*.txt`; the repository verification report records scope. Browser projects deliberately split default three-point mode from expanded mode so original unsupported-humidity assertions stay meaningful.

Automated tests cover mocked environmental transport, strict units/coverage, date limits, missing data, transient retries, unsupported questions, exact grounded claims, mocked provider output, map controls/keyboard/tile failure, comparison handoff and Inspector. A passing mocked provider test does not verify Groq uptime or model compliance.

Actual live evidence separately includes ten registry-point weather retrievals, humidity/wind retrievals, selected-location HTTP/UI retrieval and successful real OSM tile requests. Cloud language examples used labelled rule demonstration. Genuine Windows trained NLP and Groq tests are pending for this version; trained coverage of new towns cannot be inferred from registry aliases.

Warnings: existing Starlette/httpx integration and Streamlit/Altair deprecation warnings; frontend tooling may emit Vitest isolation/performance guidance and Playwright color-environment notices. These did not fail tests. No dependency upgrade is needed for this handover.

Limitations: in-memory expiring context; no multi-user authentication or durable sessions; fixed reviewed point registry; coarse gridded estimates; limited snapshot period/places; no supplemental snapshots or supplemental GenAI context; mixed-product natural-language requests need separate handling; aliases need further native-speaker review; external tiles and providers may fail or rate-limit. No hazards, pressure, wind direction/gust, snowfall or cloud-cover measurements are supported. Existing trained labels do not imply those retrieval capabilities.

Conditional GO for a supervised academic demonstration after Windows verification; not a production deployment approval. Future work could add independently reviewed locations, multilingual real-user evaluation, stronger operations/security, source-aware persisted contexts and separately validated supplemental GenAI claims. These are proposals, not completed features.
