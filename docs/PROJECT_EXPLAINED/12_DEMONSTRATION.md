# Six-minute demonstration guide

Before presenting: follow the Windows guide, verify real checkpoint health and actual Groq success, use explicit 2025-01-01 through 2025-01-07 dates, and keep Streamlit open as backup. If credentials fail, explain that environmental results still work; never call a mocked or rule result genuine inference.

- **0:00–0:40 — Vision.** Explain three-language questions, real gridded environmental evidence and optional validated explanation. State point estimates and academic scope.
- **0:40–1:35 — Trained pipeline.** Ask “Show temperature and rainfall in Gangtok from 2025-01-01 to 2025-01-07.” Show trained mode, exact seven dates, units and coverage. Expand Inspector to show actual entities and structured period.
- **1:35–2:20 — Grounding.** Show a genuinely successful explanation and its evidence. Ask “What was the warmest day?” and “What was the wettest day?” Check date/value/source. If provider is unavailable, show the honest unavailable status and preserved data.
- **2:20–3:25 — Real map.** Open `/map`, show actual OSM attribution, zoom/pan, ten markers and keyboard selection. Select Gangtok and Pelling with the same dates. Retrieve live data and inspect requested/grid coordinates.
- **3:25–4:15 — Analytics/comparison.** Show valid-day coverage, daily extremes/ties and retrieved-portion monthly labels. Follow comparison handoff, confirm both selected towns, then submit the trained comparison. Explain that nearby points can share a model cell.
- **4:15–5:00 — New variables.** Retrieve humidity (%) and wind speed (m/s) through the map's separate controls. Explain mean-daily definitions and their separate source blocks. Do not claim a humidity GenAI explanation.
- **5:00–5:40 — Safety and languages.** Show a reviewed Hindi or Nepali query with genuine inference if locally verified. Ask an unsupported pressure or hazard question: expect rejection/clarification, not invented values. Demonstrate tile failure fallback if needed without disrupting the live network.
- **5:40–6:10 — Backup and limits.** Show independent Streamlit, the test totals and documentation index. State external-service dependence and pending evidence honestly.

Use the same validated period in charts, summaries and follow-ups. Do not treat the 1–7 January snapshot fixture as live retrieval. If a stage fails, explain the failure rather than substituting a fabricated success.
